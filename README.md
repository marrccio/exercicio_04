# Exercício 04

Repositório do exercício 1.4 da disciplina de Agentes de IA.

## Objetivo

Este exercício pratica o fluxo de **Pull Request** e **Merge** no GitHub com o apoio de um assistente de IA, executado inteiramente pelo terminal com `git` e GitHub CLI (`gh`):

1. Criar uma branch de feature a partir da `main`.
2. Fazer alterações, commit e push da branch.
3. Abrir um Pull Request com `gh pr create`.
4. Revisar o estado do PR com `gh pr view`.
5. Fazer o merge com `gh pr merge` e remover a branch.
